# Code of Conduct

This is a public space for Smart Dash users to ask questions, report issues, share ideas, and help
each other out. Grosnet Tech reads and responds here, time permitting.

- Be respectful. Disagreement is fine; personal attacks, harassment, and spam are not.
- Stay on topic — Smart Dash, its docs, and things built with it.
- No posting other people's private information.

Posts that don't meet this bar may be edited, locked, or removed at the maintainers' discretion.
To report a problem, email **support@getsmartdash.com**.
